# Conditional Access policies

Create and list Conditional Access policies. Part of the
[Policies tour](../README.md).

| What | File | Notes |
|------|------|-------|
| List policies | [`list.py`](./list.py) | Optional state summary |
| Create a policy | [`create.py`](./create.py) | Dry-run by default |

> Creating a Conditional Access policy is a high-impact change — the example is
> dry-run unless you pass the apply flag, and it targets a named test user.
