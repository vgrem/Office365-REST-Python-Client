# List item attachments

Attachments live on a list item (distinct from document-library files). Part of
[List items](../README.md).

| What | File | Notes |
|------|------|-------|
| Upload an attachment | [`upload.py`](./upload.py) | Creates an item, then attaches |
| List attachments | [`list.py`](./list.py) | Per item |
| Download attachments | [`download.py`](./download.py) | All attachments |
| Download per attachment | [`download_per_attachment.py`](./download_per_attachment.py) | One at a time |
| Delete an attachment | [`delete.py`](./delete.py) | Remove by name |
