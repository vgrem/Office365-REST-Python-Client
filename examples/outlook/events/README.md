# Outlook events

Create and manage individual calendar events, including recurring events,
Teams online meetings, and invitee responses. Part of the
[Outlook tour](../README.md).

| What | File | Notes |
|------|------|-------|
| Create an event | [`create.py`](./create.py) | Attendees, start/end, body |
| Recurring event | [`recurring.py`](./recurring.py) | Weekly pattern |
| Respond to an invitation | [`respond.py`](./respond.py) | Accept, decline, cancel |
| Create a Teams meeting | [`online_meeting.py`](./online_meeting.py) | `isOnlineMeeting` + join URL |

For calendar-level operations (free/busy, sharing, rooms) see
[calendars/](../calendars/README.md).
